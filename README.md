# Patient Food AI — Offline/Localhost Mini Project

A Flask + SQLite academic prototype for uploading sample medical reports, extracting selected values, generating rule-based food recommendations, creating a weekly meal plan, and demonstrating notifications.

## Main technologies
- Python
- Flask
- HTML/CSS/JavaScript
- SQLite
- pypdf

## Run on Windows
Double-click `START_PROJECT.bat`.

The launcher is path-independent: it does not contain a hard-coded Windows username or Python installation directory. It detects Python, creates a project-local virtual environment, installs dependencies, and starts the Flask app.

See `INSTALL_AND_RUN.txt` for details.

## Important
The food recommendations are for academic demonstration only and are not medical diagnosis or treatment advice.
